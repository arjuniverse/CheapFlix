# CheapFlix

Premium OTT subscription management and streaming showcase web app built with **React + Vite + TypeScript**.

CheapFlix helps users discover movies & series, compare OTT subscription prices, manage watchlists, and simulate subscription sharing — all inside a modern Netflix-style UI.

---

# ✨ Features

* Premium OTT-style UI
* Netflix-inspired homepage
* Movie & Series browsing
* Search and genre filtering
* Watchlist management
* OTT subscription comparison
* Split-cost calculator UI
* Responsive design
* Framer Motion animations
* Dark glassmorphism theme
* Local mock data support
* Fully frontend project
* Runs locally without backend

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/arjuniverse/CheapFlix.git
```

Move into the project folder:

```bash
cd CheapFlix
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
